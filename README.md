# NoteFlow

Static website export. The course folders open in Google Drive. The ECO 111 exam PDF is included in notes/.

## Publish with GitHub Pages

1. Extract the ZIP. Create your GitHub repository.
2. Upload the contents of the NoteFlow folder to the repository root. The index.html file should be at the root. Keep the notes/ folder intact.
3. Go to Settings → Pages. Under Build and deployment, select Deploy from a branch.
4. Choose main and / (root), then save. GitHub will display your website URL once deployment completes.

## Customize

- Edit the HTML pages to change the displayed name and static text.
- Edit style.css to change the colors and layout.
- Edit app.js to update the course catalog, folder links, and headings generated for year and semester pages.

Your website visibility and the Google Drive permissions are separate. Only publish files you want visitors to access.
